# Almamater S1 Kabinet Merah Putih

Infografis interaktif latar belakang pendidikan S1 134 pejabat Kabinet Merah Putih dan kepala LPNK, data per 3 Oktober 2026.

## Publikasi lewat GitHub Pages

1. Buat repository baru di GitHub (mis. `almamater-kabinet`), set **Public**.
2. Klik **Add file → Upload files**, unggah `index.html` (dan `README.md` ini), lalu **Commit changes**.
3. Buka **Settings → Pages**. Pada *Source* pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu 1–2 menit. Situs tersedia di `https://<username>.github.io/almamater-kabinet/`.

`index.html` sudah berdiri sendiri (font, gaya, data, dan skrip tertanam), jadi tidak perlu file lain.
